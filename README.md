IARA Fishing Management System 🐟
A Python school project simulating an information system for Bulgaria's Executive Agency for Fisheries and Aquaculture (ИАРА / IARA).
About the Project
This project models the core workflows of IARA — the Bulgarian government agency responsible for regulating fishing activities. The system handles fishing vessel registration, permit management, catch logging, inspector tools, and amateur fishing ticket sales.
Technologies Used

Python 3.10+ — core language
Flask — web framework
SQLite — local database for storing records
HTML/CSS — frontend templates
Jinja2 — templating engine (built into Flask)
