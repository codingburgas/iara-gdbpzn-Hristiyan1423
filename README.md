> 🎓 **School Project** — A web-based information system for Bulgaria's Executive Agency for Fisheries and Aquaculture (ИАРА / IARA).

---

## 📖 About the Project

This project models the core workflows of IARA — the Bulgarian government agency responsible for regulating fishing activities. The system handles fishing vessel registration, permit management, catch logging, inspector tools, and amateur fishing ticket sales.

---

## ✨ Features

- 🚢 **Vessel Registry** — manage fishing ships and their details
- 📄 **Fishing Permits** — issue, track, and revoke annual permits
- 📓 **Catch Logbook** — log fishing trips and catch quantities
- 🔍 **Inspector Tools** — verify permits and issue fines
- 🎣 **Amateur Tickets** — buy and validate recreational fishing licenses
